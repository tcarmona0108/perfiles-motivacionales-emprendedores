Brindé apoyo estadístico en una tesis doctoral enfocada en el emprendimiento, donde participé en el análisis integral de los datos recopilados. Realicé un análisis descriptivo de las respuestas y validé la calidad de los datos para preparar un análisis factorial. Implementé un análisis factorial exploratorio mediante Componentes Principales (CPA) con rotación ortogonal Varimax, seguido de un análisis factorial confirmatorio utilizando Modelos de Ecuaciones Estructurales. Finalmente, desarrollé modelos de machine learning, como regresión logística y random forest, para predecir el potencial emprendedor de los participantes.
